# Катапульта

## Производство

Катапульта производится в существующей мастерской **Workshop**. Рецепт автоматически добавляется
в том числе к старым спискам с луком и щитом. Стандартный индекс — **2**, название «Катапульта».
Начальная стоимость: **30 дерева + 10 железа + 5 камня**, **90 секунд работы одного ремесленника**.
Несколько присутствующих ремесленников вносят время по существующим правилам производства.

1. Назначьте в Workshop поле **Catapult Prefab**: `Assets/Learnig/Episode11_Assets_RTS/Catapult.prefab`.
2. Создайте у мастерской пустой Transform **CatapultSpawnPoint** и назначьте его в **Catapult Spawn Point**.
   Расположите его на земле снаружи здания; для машины нужен радиус свободного места около 1.3 м.
3. Если точка не задана, используется вход со смещением наружу. Если префаб не назначен,
   создаётся временная машина из примитивов с теми же базовыми компонентами.
4. Мастерской нужны дорога, нанятые ремесленники и носильщики для физической доставки сырья.
5. Для кнопки производства используйте существующий ProductionRecipeRow с Recipe Index=2
   либо Workshop.QueueCatapult(). Для автоматически создаваемых строк рецепт появится при повторном открытии панели.
6. Спрайт назначается через **Workshop → Catapult Icon**. Свой Canvas менять автоматически скрипт не будет.

Готовая катапульта появляется как отдельный юнит у мастерской. Это не предмет в рюкзаке носильщика.
За один заказ создаётся одна машина. При занятом выходе прогресс остаётся на 100%,
очередь и материалы сохраняются; выход проверяется повторно. Сырьё окончательно расходуется после успешного появления.
Отмена заказа до появления сохраняет неиспользованные материалы в мастерской.
Toggle Repeat действует по общим правилам панели; для конечного производства отключите повтор.

## Префаб

Поставляется временная модель: рама, метательный рычаг, четыре колеса и индикатор выделения.
Можно перетащить префаб на карту для отдельной проверки боя. Это прототип, не готовая художественная модель.

На корне: Unit, NavMeshAgent, GOScript, AttackController, ResourcesMove, GettingResources, Catapult.
Роль машины — **Transport**; она не является жителем, не проходит обучение в казарме, не ест в таверне
и не отправляется в больницу. Экипаж и привязанная лошадь не требуются.
Катапульту можно включить в ArmyGroup и группы Ctrl + цифра. Общий марш учитывает её низкую скорость
и крупный радиус. На стены машина не поднимается.

## Управление

- ПКМ по земле — движение.
- ПКМ по врагу — явная атака; к далёкой цели машина пытается выйти на дистанцию стрельбы.
- T + ЛКМ — движение с остановками для обстрела доступных вражеских зданий; после уничтожения цели продолжает маршрут.
- X — отмена текущей цели и движения. Автоматический обстрел зданий в радиусе остаётся разрешён.
- H — остановка на месте; автоматического преследования целей при этом нет.

Автоматически выбираются вражеские здания в дальности, включая стены/ворота/башни.
Вражеский юнит может быть задан явной атакой. Цель ближе минимальной дальности не обстреливается:
нужно отвести машину, её статус показывает причину. Катапульта не наносит ближних ударов.

## Настройки Catapult

| Поле | Начальное значение |
|---|---:|
| Unit Max Health | 250 HP |
| Move Speed | 1.8 м/с |
| Minimum / Maximum Range | 8 / 40 м |
| Deploy Seconds | 2 с после остановки/смены цели |
| Reload Seconds | 8 с |
| Building Damage | до 90 за прямое попадание |
| Укрепления WallSegment | дополнительный множитель ×1.5 |
| Unit Damage | до 20 до применения защиты |
| Splash Radius | 3 м |
| Arc Height | 10 м |

Launch Point — точка выпуска камня; при отсутствии используется верхняя передняя точка машины.
Throwing Arm — необязательный рычаг с простой анимацией выстрела вокруг локальной X.
Projectile Prefab — необязательный объект с SiegeProjectile, иначе создаётся временный шар.
При собственной анимации оставьте Throwing Arm пустым, чтобы не было двух владельцев движения рычага.
Момент развёртывания и перезарядки не требует контроллера пехотных анимаций.

Камень летит по дуге к фиксированной точке без самонаведения и проверяет столкновения по частям траектории.
Препятствие может перехватить снаряд. На попадании применяется один урон по каждому объекту независимо от числа коллайдеров;
урон по площади уменьшается с расстоянием. Своим и нейтральным объектам урон не наносится.
В текущей версии камни не расходуют дополнительный складской боезапас.

## Проверки

Компиляция и Tests/LogisticsChecks: рецепт/старые списки, реальная доставка трёх материалов,
полное время производства, занятый выход, одно появление без дублирования, отмена, дальность и радиус поражения.

В Unity проверить: заказ с ремесленником и носильщиком; полный выход и его освобождение; свой префаб;
обстрел стены и ворот; преграду на траектории; движущуюся цель; минимальную дальность;
несколько коллайдеров у здания; своих бойцов в зоне попадания; T, X и перемещение после выстрела.
Полный Play Mode и импорт нового префаба автоматически не проверены.

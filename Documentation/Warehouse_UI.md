# Ресурсы и отдельные склады

Список ресурсов взят из GDD/GDD_Lords_of_the_Valley_New.md, версия 1.2.

## Настройка Unity

1. Добавить WarehouseStorage на каждый префаб склада. Capacity — общий лимит
   предметов, по умолчанию 2000. Например, 100 дерева и 50 рыбы занимают 150 мест.
   Начальные ресурсы конкретного склада задаются в этом компоненте.
   Начальное заполнение в инспекторе ограничивается вместимостью.
2. Добавить WarehouseUI на панель склада. Назначить отдельные TMP-тексты
   Wood Text, Stone Text, Iron Text, Gold Text, Wheat Text, Flour Text, Bread Text,
   Food Text, Fish Text, Meat Text, Berries Text, Sword Text, Spear Text, Bow Text,
   Shield Text. Неназначенные поля пропускаются.
3. Capacity Text показывает «занято / лимит»; Used Capacity Text — занято;
   Free Capacity Text — свободно. Contents Text — необязательный общий список.
4. В UiSelectBuilding склада назначить UIPanel или Panel Name. При выборе
   здания WarehouseUI автоматически получает его WarehouseStorage, в том числе
   когда несколько складов используют одну панель. Для постоянной отдельной
   панели можно вручную назначить Warehouse в WarehouseUI.
5. В ResourcesManager назначить пять полей верхней панели: Wood Text,
   Stone Text, Food Text, Iron Text, Gold Text.

## Учёт

Food / GetAmount(ResourceType.Food) — сумма готовой еды, хлеба, рыбы, мяса и ягод.
Пшеница и мука не входят в еду. Prepared Food — готовая еда без указанного вида:
она добавляется к сумме, а не дублирует хлеб/рыбу. В рюкзаке это PreparedFood.

Вместимость считается по физическим предметам: общий Food не прибавляется
к уже учтённым хлебу, рыбе и остальным продуктам второй раз.

Каждый WarehouseStorage хранит свои ресурсы. ResourcesManager суммирует запасы
активных складов, а покупка зданий и юнитов списывает ресурсы из этих запасов.
При выключении/уничтожении склада его запас исключается из общей суммы.

Носильщик разгружается в конкретное здание; если места мало, остаток остаётся
в рюкзаке. Нанятый в склад носильщик всегда возвращается к своему складу и ждёт там
свободного места. Он не сдаёт груз в чужой склад по пути. Привязка при найме обязательна для всех профессий.
Непривязанный носильщик выбирает ближайший склад со свободным местом.

Старые значения ресурсов в ResourcesManager служат стартовым запасом:
автоматически распределяются по доступным складам в пределах вместимости.
Неразмещённый остаток ждёт свободного места и не учитывается как доступный.
Существующие активные здания с тегом Warehouse получают компонент автоматически
при запуске; для новых префабов рекомендуется добавить его заранее.

## API

- warehouse.AddResource(ResourceType.Iron, 10) возвращает фактически принятое число.
- warehouse.Deposit(cargo) переносит груз и уменьшает рюкзак на принятое количество.
- warehouse.TrySpendResource(ResourceType.Food, 5) списывает 5 еды из её подвидов.
- warehouse.SetCapacity(500) меняет лимит, если он не меньше занятого места.
- panel.Bind(warehouse) переключает панель на выбранный склад.
- ResourcesManager.Instance.GetAmount(ResourceType.Food) — вся доступная еда.
- ResourcesManager.Instance.AddResource(...) распределяет ресурс по складам
  и возвращает принятое число; вызывающий сохраняет остаток.

Сцена и префабы не изменены; текстовые поля необходимо назначить в инспекторе.

## Привязка рабочих к месту найма

WorkplaceHiring передаёт свой gameObject в ResourcesMove.SetRole(role, workplace).
Рабочий хранит ссылку в AssignedWorkplace; она сохраняется при замене модели.
После найма рабочий сначала подходит к своему зданию, затем начинает работу.
Лесоруб сдаёт дерево только на свою лесопилку, рыбак — в свою рыболовню,
каменщик — в свой StoneHouse, носильщик — на свой склад.
Если работы нет, рабочий возвращается к своему зданию; строитель делает
это, когда нет подходящих стройплощадок. Увольнение снимает привязку.
Чужие здания не принимают груз нанятого работника при проходе мимо.
Заданные на сцене рабочие без места найма сохраняют поиск ближайших зданий.

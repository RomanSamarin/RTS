# Лучники и полёт стрел по дуге

Стрела теперь летит по фиксированной параболе от лука к точке прицеливания.
Время рассчитывается по расстоянию и Arrow Speed, с учётом Min Flight Time.
Высота дуги задаётся отдельно: это игровая параболическая траектория, а не Rigidbody
со стандартной гравитацией Unity. Rigidbody и коллайдер на самой стреле не нужны.

## Настройка

Используется прежний префаб `Assets/_Game/Models/arrow.prefab`; ссылки Archer.Arrow Prefab
и Bow Point сохраняются. Новые параметры компонента Arrow:

- Arc Height Per Meter = 0.15: дополнительная высота дуги над прямой между концами.
  На дистанции 12 м это примерно 1.8 м дополнительной высоты в середине.
- Minimum Arc Height = 0.5 м; Maximum Arc Height = 6 м.
- Lead Moving Target: включено. При запуске учитывается скорость NavMeshAgent цели.
- Max Lead Seconds = 1.5: предел упреждения.
- Rotate To Direction: модель направлена по касательной траектории.
- Model Forward Axis = Auto: продольная ось определяется по геометрии MeshFilter,
  включая поворот вложенной модели. При необходимости можно явно выбрать +X/-X/+Y/-Y/+Z/-Z.
- Reverse Model Axis: развернуть наконечник, если геометрия направлена в отрицательную сторону.
- Model Roll: поворот оперения вокруг древка, без изменения направления полёта.
  Наклон вверх/вниз определяется траекторией, а не Rotation корня префаба.
- Hit Radius: радиус проверок попадания, старое значение 0.35 м сохраняется.

Параметры нужно менять на префабе стрелы, а не на экземпляре в полёте.
В Archer.Shot Blocking Layers должны входить земля, здания и препятствия,
а для физических попаданий в других юнитов — также их слои. Триггеры игнорируются.
Точку Bow Point разместить возле лука над землёй, вне стен.

## Попадания

После запуска стрела не доворачивает к цели. Движение учитывается только при выборе
точки упреждения: резкий поворот, остановка или смена скорости могут вызвать промах.
При промахе урон не начисляется автоматически. Если цель погибла, стрела продолжает
свой полёт и может столкнуться с другим объектом.

Каждый шаг проверяется SphereCastNonAlloc. При низком FPS используются подшаги,
чтобы прямые проверок не срезали заметный участок дуги. Дополнительная проверка
отрезка со сферой цели сохраняет работу целей без коллайдера.
Урон наносится один раз через Unit.TakeDamage(..., CombatHitKind.Ranged): контртипы,
щит, направление попадания и эффекты построения продолжают учитываться.
Союзный юнит останавливает стрелу, но не получает урон. Стены останавливают стрелы;
урон зданию наносится лагерю или явно выбранному зданию-цели.

Перед выстрелом Archer проверяет всю дугу, а не прямой луч к цели.
Низкое препятствие можно перестрелить; высокое перекрывает выстрел.

## Сокращение лишней работы

- Поиск объектов по тегу разделён между лучниками, общий кэш обновляется раз в 0.25 с.
- Дистанция до кандидата проверяется до проверки видимости и через квадрат расстояния.
- RaycastAll заменён на SphereCastNonAlloc с переиспользуемыми буферами.
- Видимость автоматической цели проверяется с интервалом, а не каждый кадр.
- При перекрытом выстреле повторная попытка откладывается на 0.2 с.
- Имена состояний анимации и хеш параметра isAttacking кэшируются.

Численное ускорение нужно измерить в Profiler на целевой карте; пул стрел пока не добавлен.

## Проверка в Play Mode

1. Неподвижная цель на 10–14 м: видна дуга и разворот вниз при снижении.
2. Цель на стене и цель под стеной: проверить высоту концов и препятствия.
3. Прямолинейно бегущий противник: проверить упреждение; резко сменивший направление — промах.
4. Низкая ограда и высокая стена: первая перестреливается, вторая блокирует дугу.
5. Убить цель во время полёта: стрела не исчезает мгновенно и не начисляет урон удалённой цели.
6. Проверить 1×/2×/4×, паузу, большое количество лучников, бой/голод/ручной приказ.

Изолированные тесты проверяют геометрию параболы и пересечение отрезка с целью.
Реальные Physics, анимации и производительность требуют проверки в сцене Unity.

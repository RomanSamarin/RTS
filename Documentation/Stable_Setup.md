# Конюшня

## Готовые префабы

- `Assets/Learnig/Episode11_Assets_RTS/Stable.prefab`: конюшня с простой временной моделью,
  коллайдером, BuildingHealth, Constructable, UiSelectBuilding и вырезающим NavMeshObstacle.
- `Assets/Learnig/Episode11_Assets_RTS/StableHorse.prefab`: временная модель из кубов,
  CartHorse, Unit (100 HP), NavMeshAgent, GOScript, AttackController и GettingResources.
- В Database добавлен **ID 69**. Строительство стоит 40 дерева, 20 камня, 10 золота.
  Стоимость резервируется и доставляется существующими строителями.

Готовые префабы нужны для проверки механики; художественные модели и анимации не добавлены.

## Подключение в сцене

1. На своей кнопке строительства назначить `BuyBuilding.databaseItemId = 69`
   и `BuyBuilding.OnButtonPlacement()`. Либо вызвать `PlacementSystem.StartPlacement(69)`.
2. Для быстрого теста можно перетащить Stable.prefab на землю возле запечённого NavMesh.
   Не ставить Entrance внутрь другого здания: это выход лошадей и вход носильщиков.
3. Создать собственную панель Canvas с именем **StablePanel** (имя соответствует
   `UiSelectBuilding.panelName` префаба). Добавить компонент `StablePanel`.
4. Назначить `Queue Horse Button`, `Cancel Current Button`, `Cancel All Button`, TMP-тексты
   стоимости, очереди, запаса, состояния и необязательный `Progress Fill` (Image Type = Filled).
   Слушатели кнопок подключаются самим компонентом; OnClick дублировать не нужно.
   При выборе конюшни `UiSelectBuilding` вызывает `Bind`, поэтому одна панель обслуживает
   несколько конюшен. Ссылку Target вручную назначать не требуется.
5. На складе должны быть еда, золото и нанятый носильщик с доступным маршрутом.
   В `Stable.Supply Warehouse` можно ограничить склад поставки.

Если панель пока не готова, кнопки можно привязать напрямую к экземпляру конюшни:
`Stable.QueueHorse()`, `CancelCurrentHorse()`, `CancelAllHorses()`.

## Правила

Одна лошадь стоит **10 еды + 5 золота**, готовится **45 секунд**.
Еда — любая смесь хлеба, рыбы, мяса, ягод и готовой еды. Мука и пшеница не подходят.
Очередь до 10 лошадей, параметры доступны в Inspector.

Конюшня работает по собственной очереди без найма жителя. Таймер продвигается только
после физической доставки полной стоимости носильщиками. Локальный запас запрашивается
для одной ближайшей лошади, а не для всей очереди сразу. Пока ресурсов нет, заказ ждёт;
постановка в очередь сама по себе не резервирует полную стоимость на складе.

Лошадь создаётся у `Spawn Point` на поверхности NavMesh своего Agent Type.
Если путь поверхности отсутствует или точка занята NavMeshAgent, готовый заказ ждёт
освобождения выхода. Материалы списываются только при успешном появлении лошади.
При 6 свободных лошадях в радиусе 12 м работа приостанавливается: нужно увести
лошадей, сцепить их с повозками или использовать для кавалерии. Это локальное
ограничение загона, не глобальный лимит лошадей игрока.

Отмена текущего заказа сбрасывает его прогресс. Сырьё ещё не потрачено: оно остаётся
для следующего заказа. При отмене всей очереди лишние запасы автоматически забирают
носильщики обратно на склад, с сохранением конкретных видов еды. Уже начатая доставка
принимается даже после отмены, после чего её тоже можно вывезти. Выключение здания
приостанавливает очередь; уничтожение удаляет здание вместе с локальными запасами.

Лошади не занимают жильё и не создают жителей. Они используют существующие
`CartHorse.TryHitch` / `FoodCart.AttachNearestHorse` и резервирование кавалерии в казарме.
Кавалерия по-прежнему обучается в Barracks; обучение всадника в конюшню не переносилось.

## Проверка

1. Заказать лошадь без сырья: таймер не идёт.
2. Доставить еду и золото двумя носильщиками: товары не дублируются, подготовка начинается.
3. Через 45 секунд появляется одна лошадь, запас уменьшается ровно на стоимость.
4. Закрыть выход юнитом: заказ сохраняет готовность и материалы до освобождения.
5. Отменить заказ во время доставки: груз принимается и возвращается на склад.
6. Заполнить загон, затем увести одну лошадь: очередь возобновляется.
7. Привязать полученную лошадь к повозке; другую использовать для обучения кавалерии.

Изолированные тесты используют настоящий Stable и WarehouseStorage для проверки
поставок, резервов, отмены, расхода и блокировки выхода. Геометрия, навигация и сцена
требуют проверки в Unity Play Mode.

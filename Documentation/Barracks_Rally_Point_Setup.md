# Сборный пункт казармы

Продолжена пользовательская реализация в `Barracks`: поля `Ground`, `CollectedPoint`
и метод кнопки `CollectedPoints()` сохранены.

## Настройка

1. В `Barracks.Ground` выбрать слой земли (в LordsGame уже задан Ground).
2. В `CollectedPoint` назначить визуальный объект или префаб флажка.
   Если используется объект сцены, оставить исходник выключенным.
   Для новых строящихся казарм назначить именно префаб маркера в префабе казармы.
3. Кнопка «Сборный пункт» вызывает `Barracks.CollectedPoints()`.
   Существующее подключение в LordsGame сохранено.
4. Если панель общая для нескольких казарм, использовать `BarracksActionsPanel`:
   назначить `Set Rally Point Button` и при необходимости `Clear Rally Point Button`.
   Эти кнопки сами работают с текущей казармой из `Bind`; дублировать OnClick не нужно.
5. Низ модели автоматически выравнивается по земле (в том числе у куба с pivot в центре).
   `Marker Offset` задаёт дополнительное смещение визуальной модели относительно точки маршрута,
   `Rally Snap Radius` — радиус поиска поверхности NavMesh (по умолчанию 2 м).

Маркер копируется отдельно для каждой казармы. Коллайдеры и NavMeshObstacle копии
отключаются, слои переводятся в Ignore Raycast: флажок не мешает лучу и движению.
Если визуальный объект не назначен, координаты и движение работают без флажка.

## Поведение

- Кнопка включает выбор; маркер следует за курсором по подходящей поверхности.
- Обычный курсор и стандартный маркер курсора скрываются на время выбора;
  после подтверждения или отмены восстанавливается обычное управление курсором.
- Следующее отдельное нажатие ЛКМ вне UI подтверждает точку.
- ПКМ или Escape отменяют выбор, возвращая предыдущий маркер.
- Невалидный клик оставляет режим выбора включённым и сообщает об ошибке.
- Одновременно выбирается пункт только одной казармы.
- Ввод выбора не передаётся выделению юнитов, воротам, панелям зданий или построениям.
- На выходе из обучения проверяется полный путь конкретного солдата с его Agent Type
  и Area Mask. Если путь недоступен, обучение всё равно завершается, солдат остаётся
  у выхода, а `LastError` сообщает причину. Смена точки не перенаправляет уже вышедших солдат.
- Выбор пункта не доступен одновременно с размещением здания или построения.
- `ClearRallyPoint()` убирает пункт. Без пункта обучение работает как раньше.
- Уничтожение казармы удаляет её маркер; отключение прячет его и отменяет выбор.

## Проверка в Play Mode

1. Нажать существующую кнопку: клик по UI не должен сразу подтверждать точку.
2. Выбрать землю, обучить солдата: он должен пойти к флажку.
3. Начать перенос пункта и отменить ПКМ/Escape: прежние координаты сохраняются,
   выделенные юниты не получают приказ от отменяющего клика.
4. Проверить два здания: у каждого свои координаты и маркер.
5. Попробовать клик вне NavMesh и изолированную площадку: невалидная точка не
   подтверждается, а невозможный полный маршрут не блокирует завершение обучения.
6. Удалить казарму во время выбора; проверить отсутствие оставшегося маркера
   и блокировки ввода. Проверить обычное выделение и постройку стен после отмены.

Система сохранения игры пока отсутствует; координаты живут в текущей сессии.

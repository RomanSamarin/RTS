# Свободные дороги и подъезды к зданиям

Клеточная прокладка заменена свободной лентой с плавными изгибами.
Дороги бесплатны, не требуют материалов или строителей. У входа здания достаточно
любого участка дороги; связь с ратушей или складом не требуется.

## Управление

| Действие | Управление |
|---|---|
| Включить/выключить дороги | B |
| Начало дороги | ЛКМ |
| Добавить промежуточную точку изгиба | Shift + ЛКМ |
| Закончить и построить показанный участок | ЛКМ или Enter после выбора начала |
| Изменить изгиб последнего отрезка | R / Shift+R |
| Удалить последнюю контрольную точку | Backspace |
| Временно отключить привязку к двери/дороге | Удерживать Alt |
| Отменить незавершённую дорогу | ПКМ |
| Выйти из режима | Escape или ПКМ без незавершённой дороги |
| Переключить удаление дорог | Delete |

В режиме удаления ЛКМ удаляет **целый созданный участок**, подсвеченный красным.
Пересекающие его другие участки остаются. Колесо мыши продолжает управлять камерой.
Клики по UI не фиксируют дорогу. Перед окончательной установкой выполняется новая
проверка маршрута; невидимое или устаревшее превью не подтверждается.

Две точки дают прямую дорогу. Промежуточные точки создают сглаженную кривую.
На любом месте существующей дороги можно начать или закончить ответвление.
Рядом с торцом привязка выбирает точный конец, а продолжение выравнивается по его
направлению. Между соединяемыми участками добавляется округлая вставка покрытия,
закрывающая наружный клин на поворотах. Возле двери сохраняется плоский торец.
T-образные и крестообразные соединения создаются пересечением дорожных лент,
выбирать отдельную клеточную модель перекрёстка больше не требуется.

## Превью и геометрия

- Превью и готовая дорога используют один алгоритм и те же контрольные точки.
- Один участок — один меш. Превью обновляет существующий меш, а не создаёт клетки заново.
- Центр и оба края покрытия проецируются на рельеф.
- Проверяются продольный и поперечный уклон, здания и строительные площадки.
- Зелёная лента означает допустимый маршрут; красная — пересечение или крутой склон.
- Жёлтая точка обозначает привязку к входу или существующей дороге.
- Вход фиксируется с небольшим гистерезисом, чтобы не переключаться между дверями при дрожании курсора.

Параметры RoadBuilder: Road Width = 1.8 м, Sample Spacing = 0.5 м,
Snap Distance = 2 м, Maximum Road Length = 150 м, Maximum Slope = 35°.
Максимум 32 контрольные точки на участок. Ground Layer должен включать землю.
Обычный материал — временная коричневая заливка, его можно заменить через Road Material.
Для своей модели назначьте **Road Prefab** в RoadBuilder на сцене. Без назначения остаётся процедурная лента.
Префаб — статический дорожный модуль с MeshFilter и MeshRenderer: ширина по локальной X, длина по Z, верх по Y.
Для импортированной модели включите **Read/Write Enabled** в настройках импорта. Материалы сохраняются.
Модуль повторяется и подгоняется по ширине, кривой и земле; размер повторения зависит от Sample Spacing.
Используются только меши и материалы префаба, без запуска его скриптов и копирования коллайдеров.
Сделайте торцы модуля одинаковыми для стыковки. Превью остаётся простой зелёной/красной лентой.
Префаб влияет на вновь построенные дороги. Старые клеточные поля Straight/Corner Prefab не используются.

Проверки покрытия и привязки используют пространственные корзины по 8 м: для каждого
юнита не перебираются все дороги карты. Дороги не дают бонуса к скорости; предпочтение дорог при поиске пути сохранено.

## Предпочтение дорог юнитами

Готовые дорожные меши получают слой **RoadSurface** и NavMeshModifier с областью **Roads**.
Превью остаётся на Ignore Raycast и не участвует в построении навигации.
Стоимость Roads = **1**, Walkable = **3**. Юниты предпочитают дороги, но могут идти
по земле, если дорога отсутствует или объезд слишком большой. Это не строгий запрет
ходить вне дорожной сети.

`RoadNavigation` создаётся автоматически. Он выбирает наземный NavMeshSurface для
каждого имеющегося наземного Agent Type, собирает всю землю и RoadSurface через
Render Meshes и обновляет NavMesh после подтверждения, удаления или отключения дороги.
Изменения объединяются с задержкой 0.35 с; одновременно идёт один пересчёт.
Правки во время пересчёта сохраняются для следующего обновления.

Дублирующие наземные поверхности того же Agent Type временно выключаются, чтобы
старый NavMesh не обходил стоимость дорог. Водные поверхности и отдельные данные
настилов WallNavigation не перестраиваются. Для запечённых данных создаются
рабочие копии: исходные assets не изменяются. При отключении менеджера настройки
поверхностей и исходные данные восстанавливаются.

В сцене без запечённого наземного NavMesh первая инициализация синхронная;
последующие изменения выполняются через UpdateNavMesh асинхронно.
Если необходимо выбрать поверхность вручную, добавьте RoadNavigation на объект
и назначьте Ground Surface до первой прокладки дороги. Ground Layers по умолчанию — Ground.

После пересчёта активные маршруты запрашиваются повторно с сохранением приказов.
Новые GOScript-юниты получают стоимости автоматически. Ground Cost и Road Cost
можно настроить в RoadNavigation. Область называется именно **Roads**, с буквой s.

## Подъезды

`BuildingRoadAccess` автоматически добавляется к обычным зданиям с BuildingHealth.
Дорога привязывается к точке, которую этот же компонент использует для проверки работы:

1. Назначенный Connection Point.
2. Дочерний объект с точным именем **SnapPoint** (может находиться глубже в иерархии).
3. BuildingEntrance / объект Door, Entrance, Дверь или Вход.
4. Если дверь не задана — передняя сторона коллайдера по направлению transform.forward.

Создайте пустой объект SnapPoint внутри префаба здания в нужном месте входа.
Поверните его синюю стрелку Z наружу от входа: по этому направлению дорога будет подходить к зданию.
SnapPoint и явно назначенный Connection Point задают точный конец по X/Z, без выноса за коллайдер;
высота покрытия берётся с земли. Можно разместить точку внутри крыльца: разрешается заход дорожного торца
в коллайдер только у подключённого здания. Другие здания по-прежнему блокируют прокладку.
Один SnapPoint на здание; при нескольких задайте нужный вручную через Connection Point.
Для старых зданий без явной точки сохраняются нормаль стороны коллайдера и вынос двери к его наружной границе.

Для здания с необычной моделью добавьте BuildingRoadAccess **на префаб** и назначьте
Connection Point у нужного входа. В Scene View компонента показываются сфера допуска
и направление наружу. Неправильную ориентацию префаба можно компенсировать явной точкой.

Без дороги приостанавливаются производство, конюшня, обучение, найм, автоматическая
работа привязанных работников, выдача/приём грузов складом и выдача еды таверной.
Новые жители не выбирают неподключённый дом, уже заселённые не выселяются.
Запасы, грузы и прогресс сохраняются; восстановление подъезда возобновляет работу.
Ручные приказы, питание и бой работников сохраняют приоритет.

Requires Road отключает правило для конкретного здания. Стены, башни, ворота,
лагеря разбойников и стройплощадки не требуют подъезда; строительство новой площадки
возможно до дороги. Природные источники не требуют подключения.

## Кнопки и статус

Существующие вызовы StartRoadPlacement()/StartNewRoad()/StartAutomaticRoad()
сохранены. StartStraightRoad() запускает свободную дорогу, StartCornerRoad()
задаёт начальный изгиб. Старые кнопки T/Cross также запускают свободную прокладку:
перекрёсток теперь создаётся соединением с существующим покрытием.
StartRemovingRoad() включает снос, StopRoadPlacement() выключает режим.

Canvas автоматически не создаётся. Для статуса подключения добавьте
BuildingRoadStatusPanel на свою панель и назначьте TMP Status Text.

## Проверка в Play Mode

1. B → ЛКМ на земле → переместить курсор → ЛКМ: прямая дорога без сетки.
2. Добавить Shift+ЛКМ две точки вокруг дома и закончить: изгибы плавные,
   готовое покрытие соответствует зелёному превью.
3. Начать дорогу у двери, затем закончить другую у двери: проверить прямой подход
   и переход здания из «Нет дороги» в рабочее состояние.
4. Начать ответвление из середины дороги; проверить привязку и отсутствие зазора.
5. Отменить над UI, выйти за землю и вернуться, использовать Backspace/Alt/R.
6. Попытаться провести ленту сквозь дом/фундамент и по крутому склону: красное превью.
7. Удалить подъезд и построить снова: прогресс и запасы должны сохраниться.
8. Провести дорогу с небольшим объездом, подождать обновления и отдать приказ
   движения через этот участок. Юнит должен предпочесть покрытие. Удалить дорогу
   во время движения и проверить продолжение маршрута по обычной земле.
9. Во время обновления быстро добавить/удалить несколько участков: последнее
   состояние должно попасть в навигацию. Превью и настилы стен в наземный NavMesh не попадают.

Изолированные тесты проверяют сглаживание, точность концов, направления у входа,
повторяемость превью, столкновения полосы с прямоугольником и работу экономических
пауз. Физика, реальные модели, рельеф и визуальное качество требуют Unity Play Mode.

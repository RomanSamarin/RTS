# Больница

Есть код Hospital, HospitalPatient, HospitalCare и HospitalPanel, а также тестовый префаб
`Assets/Learnig/Episode11_Assets_RTS/Hospital.prefab`. Модель — временный куб, её можно заменить своим оформлением.
Здание зарегистрировано в Database.asset: **ID 70**, стартовая стоимость **40 дерева и 20 камня**.

## Быстрый запуск

1. Добавьте префаб Hospital на сцену или создайте кнопку строительства: BuyBuilding.databaseItemId=70,
   Button.OnClick → BuyBuilding.OnButtonPlacement(). Используйте актуальный Database.asset в PlacementSystem.
2. Подведите дорогу к Entrance здания. Как и другим обычным зданиям, больнице нужен подъезд.
3. Должны быть свой склад с едой и работающий носильщик. Пополнение использует существующие резервы таверны:
   никакого мгновенного списания из общего счётчика нет.
4. Запустите Play Mode, уменьшите Unit Health своего солдата после запуска и завершите его приказ движения/атаки.
   Выйдите из боя: после последнего вражеского урона учитывается существующая пауза RecentlyAttacked (5 секунд).
5. При наличии свободной койки и полного пути солдат сам придёт, станет невидимым, затем выйдет после восстановления.

HospitalPatient добавляется автоматически солдатам с ResourcesMove.Role=Soldier и GOScript. Для диагностики
в Hospital включён Debug Hospital; в Console фильтруйте по `[Больница]`.

## Настройки Hospital

| Поле | По умолчанию | Назначение |
|---|---:|---|
| Bed Count | 4 | Койки, включая места, уже зарезервированные идущими пациентами |
| Treatment Seconds | 5 | Длительность одного оплаченного цикла |
| Food Per Treatment | 1 | Расход реально доставленной еды на начало цикла |
| Healing Per Treatment | 20 | HP после завершения цикла; здоровье ограничено максимумом юнита |
| Capacity | 50 | Вместимость локального запаса еды |
| Restock Threshold | 15 | Ниже порога носильщики начинают пополнение до вместимости |
| Food Storage | необязательно | Конкретный свой склад для поставок |
| Serving Point | Entrance | Доступная точка приёма пациентов и доставки еды |
| Exit Point | Entrance | Центр поиска свободного места при выписке |

Лечение не требует нанимать лекарей в текущей версии. Цена и параметры — начальные настройки для проверки баланса.
Hospital наследует запас/доставку Tavern, но **не выдаёт порции посторонним как таверна**.
На своём префабе добавляйте Hospital, а не одновременно Tavern и Hospital.

На HospitalPatient можно настроить Search Radius (120 м) и Travel Timeout (90 с).
При активных ручных приказах, включая H, солдат их выполняет; X освобождает его для автоматического лечения.
Бой и получение вражеского урона отменяют ещё не завершённый поход в больницу и освобождают резерв.

## Поведение пациента

- Резервируется одна койка ещё до движения. Полная больница не принимает лишних пациентов.
- Солдат не уничтожается и не выключается целиком: население, снаряжение и принадлежность армии сохраняются.
- Во время лечения скрываются Renderer и Canvas, выключаются коллайдеры, аниматоры и NavMeshAgent,
  физические тела временно фиксируются. Пациент исключён из выбора, автоатаки и натиска.
- Каждая порция лечения одновременно засчитывается как питание. Второй расход на таверну не происходит.
- Без еды новый цикл не начинается. Уже оплаченный цикл завершается. При отсутствии еды голод продолжает действовать
  по обычным правилам UnitEat: больница не даёт бесплатного бессмертия.
- При потере подъезда лечение приостанавливается. Пациент и запасы сохраняются.
- Полностью вылеченный солдат возвращается к армии, в которой состоял до похода в больницу. Старый боевой приказ не восстанавливается.
  Если армии нет, она распущена, сменила сторону или солдат переназначен, он остаётся у выхода.
- Если выход занят, пациент остаётся скрытым с занятой койкой и ждёт свободного места.
- При отключении/разрушении больницы пациенты эвакуируются с текущим здоровьем, а не погибают вместе со зданием.
  При временно недоступном выходе скрытый пациент продолжает искать безопасную точку возле сохранённого выхода.
- Досрочная выписка и эвакуация не отправляют раненого в армию автоматически.
- Досрочная выписка не возвращает еду уже оплаченного цикла.

## Панель — создаётся вручную

1. Создайте панель Canvas с именем **HospitalPanel**. Префаб UiSelectBuilding уже ищет это имя.
2. Добавьте скрипт `_Game.Scripts.UI.HospitalPanel`.
3. Назначьте TMP_Text: Beds Text, Food Text, Patients Text, Status Text.
4. По желанию назначьте Discharge All Button — обработчик подключается автоматически.
5. При выборе здания UiSelectBuilding автоматически вызывает Bind для этой больницы.

Панель показывает занятые/общие койки, реальный запас еды, состояние, список пациентов, HP и прогресс текущего цикла.

## Проверки

Компиляция игровых скриптов и Tests/LogisticsChecks: конкуренция за койку, повторный резерв, освобождение,
отсутствие лечения без еды, одна оплата за цикл, пауза времени и исчерпание запаса.

В Unity отдельно проверить: двух раненых при одной койке; ручную отмену похода; бой по дороге; поставку носильщиком;
отсутствие еды; закрытый выход; разрушение больницы; сохранение населения и состава армии;
солдат с Rigidbody, несколькими моделями и полоской здоровья. Play Mode пока не пройден автоматически.

## Возвращение в армию

Назначьте солдат в ArmyGroup до лечения через существующую панель армии. После полной выписки компонент
ArmyRejoin добавляется автоматически — вручную на префаб его ставить не нужно. Группы Ctrl + 1…9 сами по себе
не создают ArmyGroup: для возврата нужна именно принадлежность к армии через ArmyMember.

Маршрут пересчитывается к текущему положению доступных бойцов армии. Пока армия движется, выздоровевший продолжает
её догонять; после приближения к остановившейся армии возвращение завершается. Точное старое место в построении не восстанавливается.
Если все остальные бойцы лечатся, используется последнее запомненное место армии. Сам возвращающийся солдат
не становится опорной точкой армии и не тянет снабженческую повозку обратно к больнице.

Новый ручной приказ отменяет возврат. Питание, бой и автоматические боевые манёвры приостанавливают его;
новое лечение завершает старый возврат, и после полного выздоровления создаётся новый. Смена армии, стороны,
профессии или роспуск армии прекращают маршрут без автоматического переназначения членства.

Настройки ArmyRejoin: Arrival Radius=4 м, Travel Timeout=180 с активного возвращения,
Blocked Path Timeout=20 с ожидания полного пути. При закрытом проходе солдат ждёт, затем останавливается;
телепортации нет. Диагностика включается Debug Rejoin, сообщения Console начинаются с `[Возврат из больницы]`.

Проверить: переместить армию во время лечения; распустить её до выписки и во время возврата;
выдать ручной приказ; выписать раненого досрочно; закрыть ворота; оставить в армии одного пациента;
проверить питание и бой по дороге. Автотесты покрывают правила допуска и завершения возврата,
интеграция маршрута с NavMesh требует проверки в сцене.

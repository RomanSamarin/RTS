# Осадная повозка для лестниц

Повозка перевозит **до двух лестниц**. Загрузка и выгрузка меняют реальные запасы. Она не участвует в населении, не ест и не атакует. Имеет здоровье, доступна для выделения и может стать целью разбойничьей засады. При убийстве действует обычная передача груза убийце через `Unit`.

## Производство в мастерской

Новый рецепт автоматически добавляется в конец `Workshop.Recipes`: **20 дерева + 4 железа, 45 секунд работы → одна пустая осадная повозка**. Лошадь и лестницы в эту стоимость не входят. Настройки рецепта можно изменить в Inspector.

- Для отдельной кнопки: `Workshop.QueueLadderCart()`.
- В стандартном списке `ProductionRecipeRow.recipeIndex = 4`; прежние индексы сохранены: лук 0, щит 1, катапульта 2, лестница 3. При пользовательском списке проверьте индекс в `Recipes`.
- Панель с префабом строки покажет рецепт после повторного открытия. Иконка — `Workshop.Ladder Cart Icon`.
- `Ladder Cart Spawn Point` — свободная точка на земле перед мастерской. Если выход занят, завершённый заказ ждёт: сырьё не теряется, несколько повозок из одного заказа не появляются.
- Без `Ladder Cart Prefab` создаётся простая тестовая повозка с двумя видимыми лестницами по мере загрузки.

Для получения редактируемого префаба: **Tools → RTS → Create Siege Ladder Cart Prefab**. Команда создаёт новый ассет в `Assets/_Game/Prefabs` без замены существующего. Назначьте его в `Workshop.Ladder Cart Prefab`, замените геометрию своей моделью. Не добавляйте `FoodCart`, `Catapult` или `CartHorse` на саму повозку.

## Лошадь и движение

Нужна отдельная живая свободная лошадь с `CartHorse` из конюшни. Подведите её к повозке на расстояние `Hitch Distance`, затем вызовите `AttachNearestHorse()` либо используйте панель. Лошадь из очереди обучения кавалерии занята и недоступна. Одна лошадь может тянуть только одну повозку — пищевую либо осадную.

Точка `Horse Hitch Point` задаёт позицию лошади относительно повозки. После привязки двигайте повозку обычным ПКМ. Лошадь следует с ней; при отцеплении/гибели лошади движение останавливается и складской резерв освобождается. Повозка не поднимается на стены. `X` останавливает повозку и отменяет загрузочный рейс.

## Загрузка и выгрузка

- `LoadNearestWarehouse()` — загрузить лестницы с ближайшего доступного склада в пределах `Loading Distance` (по умолчанию 3 м).
- `ReturnForLadders()` — самостоятельно доехать до доступного склада с лестницами и загрузиться. До отправления резервируются только доступные лестницы, максимум до двух. Если есть одна — возьмёт одну.
- `UnloadNearestWarehouse()` — вернуть лестницы на соседний склад. Если места мало, остаток остаётся в повозке.
- `DropLadders()` — выгрузить лестницы рядом на землю отдельным запасом `LootCache`. Носильщик сможет забрать его и вернуть на склад, если поблизости нет врагов. Это ещё не установленная лестница для штурма.
- `CancelLoading()` — остановить загрузочный рейс и освободить резерв. Уже загруженное остаётся в повозке.

Работают только склады союзной стороны с доступной дорогой. Загрузка рядом со складом разрешена и у стоящей без лошади повозки; рейс требует лошадь. При новом приказе движения резерв снимается. При потере склада, дороги, полного пути или отсутствии движения 30 секунд рейс отменяется с сообщением. Автоматического непрерывного пополнения нет: после погрузки повозка ждёт приказ.

## Твоя панель

Создай Canvas и добавь `SiegeLadderCartPanel`. Он не создаёт UI.

Назначь кнопки в пДля `Hitch Button`, `Unhitch Button`, `Load Nearby Button`, `Return For Ladders Button`, `Unload To Warehouse Button`, `Drop Ladders Button`, `Cancel Loading Button`. `OnClick` вручную заполнять не нужно, обработчики подписываются сами. ПДля `Cargo Text`, `Horse Text`, `Status Text` — необязательные TMP-тексты.

При `Use Selected Cart = true` работает выбранная повозка; можно выбрать вместе с ней конкретную лошадь для привязки. Без выбранной лошади ищется ближайшая свободная союзная. Для фиксированной панели выключи этот флаг и назначь `Cart` вручную. Панель не открывается автоматически при выборе: видимость подключи к своему интерфейсу.

## Сохранения и проверки

Груз, складской резерв, загрузочный рейс и связь с лошадью входят в общий снимок. Для тестовой повозки без префаба добавлено восстановление через встроенную геометрию. Пользовательские префабы используют каталог сохранений. Полная проверка восстановления в Play Mode ещё необходима.

Изолированные тесты проверяют производство с блокировкой выхода, одноразовый расход материалов, вместимость, конкурирующие резервы, отмену и частичную выгрузку. Компиляция не подтверждает навигацию и внешний вид.

Проверь в сцене: изготовить повозку → попытаться двигаться без лошади → привязать → загрузить две лестницы → выдать ПКМ → выгрузить → вернуть остаток на склад. Отдельно проверь две повозки у одного склада, гибель лошади, `X`, разрушение склада в пути и сохранение/загрузку во время рейса.
